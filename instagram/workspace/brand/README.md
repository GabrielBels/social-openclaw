# Brand reference

Put the brand's reference image here as `reference.png` before deploying: a finished post or brand sheet that shows the logo, the wordmark, the palette and the type. The deploy copies only committed files, so commit it in your copy of the repository.

Use this file as an image input to each slide generation, not merely as a written description. Preserve the logo and wordmark, the palette, the type hierarchy and generous margins. Its composition belongs to that one image and is not a slide template; cover backgrounds and layouts follow `SOUL.md`. Content changes to the approved topic; a slogan in the reference is not repeated as the topic.

A logo or interface must not be invented. Product demonstrations use an actual demo interface with fictitious data; the reference is not a product screenshot.
